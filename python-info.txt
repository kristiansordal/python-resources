# Python 3.12+ Quick Reference Notes

## Type Parameter Syntax (PEP 695)
Python 3.12 introduced a cleaner syntax for generic functions and classes:

def first[T](items: list[T]) -> T:
    return items[0]

type Point = tuple[float, float]

## f-string Improvements (PEP 701)
Quotes, newlines, and comments are now allowed inside f-string expressions:

names = ["Alice", "Bob"]
print(f"Users: {", ".join(names)}")

## Exception Groups & except*
Use `except*` to handle multiple exceptions raised concurrently via `TaskGroup`:

try:
    async with asyncio.TaskGroup() as tg:
        tg.create_task(fetch_user())
except* TimeoutError as eg:
    print(f"Timed out: {eg.exceptions}")
